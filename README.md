# ✨ Next Prompt

## A **modern prompt-sharing app** built with **Next.js**, powered by **Puter AI** .

## 🖼️ Screenshot

![screenshot](src/assets/images/screenshot.png)

---

## 🚀 Features

- 🧠 Generate & read AI prompts (via **Puter AI**)
- 📋 Copy prompts to clipboard
- 🌙 Light & Dark mode toggle (persists between sessions)

> This is a **frontend-only practice project**, ideal for learning and
> experimenting with AI + Next.js integration.

---

## 🧩 Tech Stack

- [Next.js 14](https://nextjs.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Headless UI](https://headlessui.com/) &
  [React Icons](https://react-icons.github.io/react-icons/)
- [Puter SDK](https://developer.puter.com/) for AI
- [Vercel](https://vercel.com/) — recommended for deployment
